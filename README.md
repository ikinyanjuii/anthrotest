# AnthroTest — Feature Intelligence System

This repository contains the Feature Intelligence assessment project in [`feature-intel/`](feature-intel/).

The project source is provided as a ZIP archive at [`feature-intel/feature-intel-source.zip`](feature-intel/feature-intel-source.zip). Download and extract it to work with the TypeScript/Express application. The archive excludes `node_modules`, local databases, and `.env` secrets; install dependencies with `npm ci` and configure your own `.env` from `.env.example`.

See [`feature-intel/README.md`](feature-intel/README.md) for setup, API endpoints, evaluation and known limitations.

**Security:** This assessment MVP does not implement authentication or authorization. Do not expose it publicly or use real customer data without adding access controls, rate limiting, managed secrets and production hardening.
